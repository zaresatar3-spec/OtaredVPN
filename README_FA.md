# Satar VPN — پروژه Android Studio

این پروژه یک پایهٔ اختصاصی Kotlin + Jetpack Compose برای مدیریت پروفایل‌های VPN است.
**محدودیت مهم:** این نسخه هنوز موتور اتصال sing-box را به‌صورت عملیاتی به رابط وصل نکرده؛ بنابراین Connect در این نسخه تونل واقعی نمی‌سازد. عمداً وضعیت را «هستهٔ اتصال هنوز پیکربندی نشده» نشان می‌دهد و ادعای اتصال موفق نمی‌کند.

## ساخت
1. Android Studio نسخهٔ جدید را نصب کن.
2. این پوشه را با گزینهٔ Open باز کن.
3. اجازه بده Gradle همگام‌سازی شود (این کار اینترنت می‌خواهد).
4. گوشی را با USB debugging وصل کن و Run بزن.

## امکانات پایه
- رابط فارسی و راست‌چین، تم تاریک
- افزودن لینک‌های `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://`, `wireguard://`
- افزودن subscription از URL و ذخیرهٔ محلی
- حذف پروفایل‌ها و انتخاب پروفایل فعال
- نمایش وضعیت اتصال به‌شکل صادقانه؛ موتور واقعی هنوز وصل نشده است

## مرحلهٔ لازم برای نسخهٔ واقعاً متصل‌شونده
برای تونل واقعی باید libbox و چرخهٔ عمر `CommandServer` / `PlatformInterface` مطابق نسخهٔ sing-box به پروژه اضافه شود، پیکربندی استاندارد sing-box از هر URI تولید شود، و تست روی دستگاه واقعی انجام شود. مستندات/منبع رسمی:
- https://github.com/SagerNet/sing-box-for-android
- https://github.com/singbox-android/libbox
- https://sing-box.sagernet.org/installation/clients/sfa/

پروژهٔ رسمی SFA تحت GPL-3.0-or-later است؛ اگر از کد آن مشتق می‌سازی، رعایت مجوز و انتساب لازم است. این پروژه فعلاً کپی کد رسمی SFA نیست.
